# OpenBook
A Qlik Sense extension that allows to add master items and simulate a book flipping pages

Author: Ivan Felipe ivan.felipe@qlik.com

Updated: 3rd Nov 2026

Make great presentations with transitions like page flip.

1st  version:
- OpenBook Extension
  
  Download the file OpenZook.zip and import it in Qlik Cloud or Qlik Sense Enterprise
  You'll find an app example with a funny topic, the Big Techs CEOs
  
- How it works
  
  Just drag and drop the extension, use the setting Pages to add Master Visualizations, 1 per page
  Add as much pages as you need, it just render the visualizations as the user moves through the presentation so don't get under performance when you have many
  Basic customization allowed like fonts, shadows, texts...
